# assets

Local visual assets used by the profile README. Swap files to customize — the README keeps the same relative paths, so nothing else needs to change.

## Slots

| Slot | Current file | Replace with |
|---|---|---|
| Hero banner | `banner-final.gif` (composited from `banner.gif`) | drop your own `banner.gif`, then run `python assets/generate-banner.py` |
| Wave divider | `divider.svg` | `divider.gif` |
| Animated emojis | — use `emojis/` | drop GIFs such as `hello.gif`, then reference them with `<img src="./assets/emojis/hello.gif" width="28" />` |
| Side decorations | — use `decorations/` | drop GIFs such as `left.gif` / `right.gif` and reference them in the README |

## Hero banner pipeline

- `banner.gif` — the raw background animation (untouched source).
- `banner-final.gif` — the banner the README actually shows: `banner.gif` with a flat on-palette developer overlay baked onto every frame. Generated by `generate-banner.py`, so details text, colors and layout are all reproducible.
- `banner-overlay.svg` — the overlay design source (editable; only a reference, not fetched by GitHub).
- `banner-preview.png` — static preview of frame 0 (convenient for quick checks).

To swap the banner: replace `banner.gif`, run `python assets/generate-banner.py`, and commit both `banner-final.gif` and (optionally) `banner-preview.png`.

## How the overlay is composited

The original GIF keeps its 36 frames, 60 ms timing and infinite loop — nothing is lost. Because Pillow cannot reproduce the original encoder's 2.7 MB output, re-encoding the full animation costs ~6 MB; blending translucent (glass) effects then doubles it again. So the overlay is drawn with a handful of **solid** colors, each inserted verbatim into the GIF's 256-color global palette, and composited by *replacing palette indices*:

- The animated background outside the overlay keeps its original colors (frames 1+ decode as RGBA due to the source's transparency flag, so those frames are re-mapped to the nearest global-palette entry without dithering — max deviation stays imperceptible).
- The 7 palette slots repurposed for the overlay are chosen to be rare and color-close, so the few re-colored background pixels are invisible.
- Result ≈ 5.3 MB at 1200×675 (1.99× the original) — the price of one shared global palette and no per-frame encoding tricks. GIFs that big are fine for a README hero, but if you want it lighter, reduce `banner.gif`'s size (fewer frames / smaller canvas) and re-run the generator.

To tune the design, edit `assets/banner-overlay.svg` and mirror the geometry in `generate-banner.py` (`build_overlay`).

## Tips

- Keep paths relative, e.g. `./assets/banner.gif` — they resolve from the repo root.
- Prefer your own GIFs or royalty-free / CC0 ones; avoid hotlinking random GIFs (they break and can be removed without notice).
- Small GIFs (1048px or less wide, under ~2 MB) keep the profile fast.
- Replace the SVG files with GIFs is optional — the current SVGs already animate on their own.
